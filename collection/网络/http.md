HTTP 知识点总结

# URL 

协议 + 域名或者IP + 端口号（默认80/443） + 路径（/xxx） + 查询字符串(?xxx) + 锚点(#xxx)

# 现代浏览器的两种缓存方式
1. 强缓存：通过 HTTP 头部的 Cache-Control 和 Expires 来控制，浏览器会直接使用缓存的资源。
2. 协商缓存：通过 HTTP 头部的 Last-Modified 和 ETag 来控制，浏览器会向服务器发送请求，服务器根据资源是否被修改来决定是否使用缓存。

# DNS域名解析
1. 用户在浏览器中输入 URL，浏览器首先检查本地缓存是否有对应的 IP 地址。
2. 如果没有，浏览器会向 DNS 服务器发送请求，查询域名对应的 IP 地址。
3. DNS 服务器会返回 IP 地址，浏览器再向该 IP 地址发送 HTTP 请求。

# CDN服务（ISP负责将DNS解析结果定位到我们的服务器）
CDN（内容分发网络）是一种通过分布式服务器将内容缓存到离用户更近的节点上，以提高访问速度和可靠性的技术。CDN 可以减少服务器负载，提高网站性能。
解决问题：
- 减少延迟：通过将内容缓存到离用户更近的节点上，减少了数据传输的距离和时间。
- 提高可靠性：CDN 可以在多个节点上缓存内容，即使某个节点出现故障，用户仍然可以从其他节点获取内容。
- 减少服务器负载：CDN 可以分担服务器的流量，减少服务器的压力，提高网站的性能。
- 提高安全性：CDN 可以提供 DDoS 防护、SSL 加密等安全功能，保护网站免受攻击。
- 支持大规模流量：CDN 可以处理大量的并发请求，支持高流量的网站。
